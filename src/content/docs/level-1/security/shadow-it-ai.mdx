会社で資料を作成していたところ、ファイルの容量が大きすぎて、メールで送信できませんでした。

そこで、普段から個人的に利用しているクラウドストレージにファイルをアップロードし、共有リンクを相手に送りました。

無事に資料を共有でき、仕事も進みました。

一見すると、ITを上手に活用して問題を解決したように見えます。

しかし、このような行為が会社にとって大きなリスクになることがあります。

## シャドーITとは

シャドーIT（Shadow IT）とは、企業や組織が承認・管理していないIT機器やソフトウェア、サービスを業務で利用することです。

Shadowには「影」という意味があります。

会社の管理が及ばないところで利用されるITという意味で、シャドーITと呼ばれています。

例えば、次のような行為が該当します。

| 利用目的 | シャドーITの例 |
| --- | --- |
| ファイル共有 | 個人のGoogleドライブに社内資料を保存する |
| メール | 会社の資料を個人のメールアドレスに送信する |
| 業務連絡 | 未承認のチャットサービスを利用する |
| データの持ち運び | 無許可で私物のUSBメモリを使用する |
| 業務効率化 | 未承認のソフトウェアをインストールする |
| システム開発 | 未承認のクラウドサービスを利用する |

これらの機器やサービス自体が危険というわけではありません。

**会社が把握・管理できない状態で業務に利用されることが問題なのです。**

参考：[IBM「シャドーITとは」](https://www.ibm.com/jp-ja/think/topics/shadow-it)

## なぜ会社はITを管理するのか

会社が正式に導入しているITサービスでは、さまざまな管理が行われています。

誰が利用できるのか、どのような情報を保存してよいのか、退職した従業員のアクセスをどう停止するのか。

問題が発生した場合に備えて、利用記録を残すこともあります。

<ShadowITDiagrams kind="management" />

例えば、従業員が個人のクラウドストレージに業務資料を保存したとします。

その従業員が退職した場合、どうなるでしょうか。

会社は社内システムのアカウントを停止できますが、従業員の個人アカウントまで停止できるとは限りません。

業務資料がどこに保存されているのか、誰が閲覧できるのか、削除されたのかさえ分からなくなる可能性があります。

情報漏洩が起きていなかったとしても、情報を適切に管理できないという問題が残るのです。

## シャドーAIとは

生成AIの普及によって、シャドーITの問題はAIの利用にも広がっています。

シャドーAI（Shadow AI）とは、企業や組織が承認・管理していないAIツールや機能を業務で利用することです。

シャドーITのうち、AIの利用に関するものと捉えることができます。

<ShadowITDiagrams kind="relationship" />

例えば、会社が承認していない環境で次のような利用をすることです。

- 個人の生成AIアカウントに社内資料を読み込ませる。
- AI翻訳サービスに取引先とのメールを入力する。
- AI議事録サービスで社内会議を録音する。
- AIコーディングツールに社内のプログラムを読み込ませる。

AIを利用する際には、文章やファイル、画像、音声など、さまざまな情報を外部サービスに送信することがあります。

その情報がどこに保存され、どのように扱われるのかは、サービスの契約や利用設定によって異なります。

会社がその内容を確認していなければ、適切な情報管理ができません。

参考：[IBM「シャドーAIとは」](https://www.ibm.com/jp-ja/think/topics/shadow-ai)

## シャドーAI特有のリスク

従来のシャドーITが抱えるリスクに加え、AIには特有の注意点があります。

| リスク | 内容 |
| --- | --- |
| 情報の二次利用 | 入力情報がAIの改善や学習などに利用される可能性がある |
| 誤情報 | AIの誤った回答が業務上の判断に利用される |
| 権利関係 | 生成物の利用が著作権や契約上の問題につながる場合がある |
| 利用実態の把握 | どの情報を入力し、どの回答を業務に使ったのか確認できない |

情報を送信することだけでなく、AIから得た回答を業務に利用することにもリスクがあります。

参考：[IPA「AI利用者のためのセキュリティ豆知識」](https://www.ipa.go.jp/digital/ai/security/ai_security_tips.html)

## 悪意がなくても発生する

シャドーITやシャドーAIは、必ずしも悪意を持った従業員によって発生するものではありません。

仕事を早く終わらせたい。

もっと便利な方法を使いたい。

会社が用意しているツールでは、やりたいことが実現できない。

こうした理由から、従業員が自分で解決方法を探すことがあります。

<ShadowITDiagrams kind="causes" />

シャドーITの発生は、現場が必要としている環境を、会社が十分に提供できていないことの表れである場合もあります。

## 禁止するだけでは解決しない

もちろん、従業員は会社の定めた利用ルールを守る必要があります。

一方で、会社側も、なぜ従業員が未承認のサービスを必要としているのかを考える必要があります。

安全に利用できるサービスを提供する。

新しいサービスを申請・審査できる仕組みを作る。

利用できる範囲や、取り扱ってよい情報を明確にする。

このように、ITの活用を促進しながら、適切に管理するという考え方は、ITガバナンスやAIガバナンス（組織として利用の方針・責任・監督を整える仕組み）にもつながります。

## 今日のなるほど

冒頭では、従業員が個人のクラウドストレージを使って、仕事上の問題を解決しました。

問題を解決するための工夫そのものは、決して悪いことではありません。

しかし、便利に利用できることと、安全に管理できることは別の問題です。

シャドーITやシャドーAIを理解すると、会社がなぜ利用するサービスを指定したり、利用申請を求めたりするのかが見えてきます。

**ITの活用と情報の管理は、対立するものではなく、両立させるべきものなのです。**
