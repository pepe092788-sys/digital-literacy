スマートフォンやPCを使っていると、ソフトウェアの更新を求められることがあります。ニュースでは、企業の情報漏えいや新しい詐欺の手口が報じられています。

セキュリティの知識を身につけても、新しい弱点や攻撃手法は次々と発見されます。

そこで知っておきたいのが、日々のセキュリティ情報を発信している機関やメディアの存在です。すべての攻撃手法を覚える必要はありません。必要な情報を、必要なときに確認できる場所を知っていることも大切な知識です。

## 国内の公的機関・専門機関

まずは、次の四つの情報源を知っておくと役立ちます。SNSは各機関の公式サイトで案内されているX（旧Twitter）のアカウントです。

### IPA（情報処理推進機構）

日本のITに関する独立行政法人です。重要な脆弱性の注意喚起だけでなく、一般利用者や企業向けの対策資料も公開しています。「情報セキュリティ10大脅威」は、どのような危険が注目されているかを知る手がかりになります。

- [情報セキュリティ](https://www.ipa.go.jp/security/)
- [重要なセキュリティ情報](https://www.ipa.go.jp/security/security-alert/)
- [X：@ICATalerts](https://x.com/ICATalerts)（[公式アカウント案内](https://www.ipa.go.jp/socialmedia/x.html)）

### JPCERT/CC（JPCERTコーディネーションセンター）

コンピュータやネットワークに関するセキュリティ上の事件・事故への対応を支援する専門機関です。攻撃の動向、脆弱性の注意喚起、対策方法などを発信しています。

個別の情報を追いきれない場合は、重要な情報をまとめたWeekly Reportも参考になります。

- [公式サイト](https://www.jpcert.or.jp/)
- [Weekly Report](https://www.jpcert.or.jp/wr/)
- [X：@jpcert](https://x.com/jpcert)（[公式アカウント一覧](https://www.jpcert.or.jp/twitter.html)）

### JVN（Japan Vulnerability Notes）

IPAとJPCERT/CCが共同で運営する脆弱性情報のサイトです。ソフトウェアや機器のどの部分に安全性の問題があるのか、どの製品やバージョンが影響を受けるのか、どう対策すればよいのかといった情報を確認できます。

例えば、普段使用しているアプリやルーターに脆弱性が見つかったと聞いたとき、詳しい情報を調べる手がかりになります。

- [公式サイト](https://jvn.jp/)
- [X：@jvnjp](https://x.com/jvnjp)（[公式アカウント一覧](https://www.jpcert.or.jp/twitter.html)）

### フィッシング対策協議会

実在する企業などを装い、ログイン情報やクレジットカード情報などをだまし取る行為をフィッシングと呼びます。

フィッシング対策協議会では、実際に確認された偽メールや偽サイトなどについて注意喚起しています。身近な詐欺の手口を知るために役立つ情報源です。

- [公式サイト](https://www.antiphishing.jp/)
- [X：@antiphishing_jp](https://x.com/antiphishing_jp)（[公式アカウントの案内・なりすましへの注意喚起](https://www.antiphishing.jp/news/info/caution_20250402.html)）

## 実際に起きたトラブルを知る

専門メディアは、企業の情報漏えい、不正アクセス、ランサムウェア被害など、実際に社会で起きている出来事を知るのに適しています。

| サイト | 主な特徴 |
| --- | --- |
| [Security NEXT](https://www.security-next.com/) | 国内のセキュリティ事故や脆弱性、対策に関する日々のニュース |
| [ScanNetSecurity](https://scan.netsecurity.ne.jp/) | 事故の報道、専門家の解説、セキュリティ業界の動向 |
| [ITmedia NEWS セキュリティ](https://www.itmedia.co.jp/news/feature/security) | ITや社会の動向と合わせてセキュリティ問題を把握する |

ニュースを読んで疑問が生まれたら、被害を受けた企業の公式発表や専門機関の調査報告を確認してみましょう。発生直後には原因が分かっていないこともあり、後日発表された内容によって理解が変わる場合があります。

## 海外の情報源

国内だけでなく、海外にも多くの情報源があります。英語の記事を読む際には翻訳ツールも活用できます。

| サイト | 主な特徴 |
| --- | --- |
| [BleepingComputer](https://www.bleepingcomputer.com/) | 世界各地のセキュリティニュースや攻撃・障害の報道 |
| [CISA（米国のサイバーセキュリティ・インフラセキュリティ庁）](https://www.cisa.gov/) | 注意喚起や対策情報。実際に悪用されたことが確認された脆弱性をまとめたKEVカタログも公開 |
| [Microsoft Security Blog](https://www.microsoft.com/en-us/security/blog/) | 脅威の分析や防御方法など、企業の調査・技術解説 |

## 情報源を使い分ける

例えば、ニュースで「ある製品に重大な脆弱性が発見された」と知ったとします。

専門メディアは問題の存在を知るきっかけになります。IPAやJPCERT/CCの注意喚起では、その問題の重要性や対策について確認できます。JVNや製品の提供元の公式情報では、影響する製品・バージョンや修正方法を詳しく調べられる場合があります。

脆弱性が存在するという情報と、すでに攻撃が確認されたという情報は別のものです。また、脆弱性が見つかったからといって、自分の機器が必ず影響を受けるとは限りません。

まず対象製品と利用状況を確認し、提供元の案内に従って対策を検討します。会社の機器については、社内のセキュリティルールや担当者の指示に従いましょう。

## 無理なく情報を受け取る

すべてのサイトを毎日訪れる必要はありません。まずはIPA、JPCERT/CC、Security NEXTなど、目的に合う情報源をブックマークするだけでも違います。

SNSで公式アカウントをフォローしたり、対応するサイトの新着情報をRSSリーダー（複数のサイトの更新情報をまとめて読むためのツール）で確認したりする方法もあります。

SNSにはなりすましアカウントも存在します。フォローするときには、機関の公式サイトから案内されているアカウントか確かめましょう。投稿にあるリンクや生成AIによる要約だけで判断せず、重要な情報は元の発表に戻って確認することが大切です。

:::tip[今日のなるほど]
セキュリティの知識は、一度学んだら終わりというものではありません。

新しい情報を発信している場所を知り、ニュース・注意喚起・製品提供元の情報を使い分けられることも、安全にITを使い続けるための力です。
:::
