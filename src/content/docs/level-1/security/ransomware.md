ある朝、会社に出勤してパソコンを開くと、昨日まで使えていたファイルが開けなくなっていました。

受注情報も、顧客情報も、業務に必要な書類も確認できません。

画面には、データを元に戻してほしければ金銭を支払うようにという要求が表示されています。

これは単なるコンピュータの故障ではありません。

データを人質にして金銭を要求する、ランサムウェア攻撃の被害を想定した場面です。

## ランサムウェアとは

ランサムウェア（Ransomware）とは、データを暗号化したり、コンピュータを利用できなくしたりして、復旧などと引き換えに金銭を要求する悪意のあるソフトウェアです。

Ransom（身代金）とSoftware（ソフトウェア）を組み合わせた言葉で、マルウェアと呼ばれる悪意のあるソフトウェアの一種です。

コンピュータやデータを破壊することだけが目的ではなく、被害者が困る状況を作り出し、金銭を要求することに特徴があります。

## データが消えていないのに使えなくなる

ランサムウェアの代表的な手口には、暗号化という技術が使われています。

暗号化とは、第三者に情報を読み取られないよう、データを一定の規則に従って変換する技術です。

適切な鍵を持っていれば、暗号化されたデータを元の状態に戻すことができます。この処理を「復号」と呼びます。

| 状態 | データの利用 |
| --- | --- |
| 暗号化前 | 業務データを正常に読み取れる |
| 攻撃による暗号化後 | 復号に必要な鍵がなければ、通常は読み取れない |
| 復号後 | 正常に復号できれば、再び利用できる |

本来、暗号化は情報を守るための技術です。

例えば、インターネット上でクレジットカード情報を送信するときにも、通信内容を守るために暗号化が利用されています。

しかし、ランサムウェアはこの技術を悪用します。

情報を守るための技術が、正当な所有者から情報の利用を奪うために使われているのです。

## なぜ会社全体の業務が止まるのか

会社では、一台のパソコンだけで仕事が完結しているわけではありません。

多くの従業員が、共有フォルダや業務システム、データベースなどを利用しています。

攻撃によってこうした共有資源まで被害が及ぶと、複数の部署が同時に仕事を続けられなくなる可能性があります。

商品を販売したくても、在庫が分からない。

商品を出荷したくても、配送先が分からない。

取引先に請求したくても、取引記録が確認できない。

現代の企業活動は、情報システムに大きく依存しています。

ランサムウェアによる被害は、コンピュータの問題にとどまらず、事業の継続に関わる問題なのです。

## こっそり情報を盗む攻撃とは何が違うのか

情報窃取とは、許可なく情報を取得することです。盗み出した情報を売却したり、悪用したりする目的で行われることがあります。

デジタルデータは複製できるため、情報が盗まれても元のファイルは残っている場合があります。被害に気づかないまま、普段どおり仕事を続けてしまう可能性もあるのです。

一方、典型的なランサムウェア攻撃では、データを利用できなくした上で、被害者に金銭を要求します。

| 比較項目 | 情報窃取 | 典型的なランサムウェア攻撃 |
| --- | --- | --- |
| 被害の中心 | 許可なく情報を取得される | 情報を利用できなくされる |
| データの暗号化 | 必須ではない | 代表的な手口 |
| 被害への気づきやすさ | 気づきにくい場合がある | ファイルが開けなくなるなど、気づきやすい場合がある |
| 金銭の要求 | 必須ではない | 恐喝が行われる |

ただし、この二つは排他的なものではありません。情報窃取は攻撃の手口であり、ランサムウェア攻撃にも組み込まれることがあります。

## データを盗んでから脅迫する

情報を盗み出した上でデータを暗号化し、金銭を支払わなければ盗んだ情報を公開すると脅迫する手口があります。

これを「二重恐喝（ダブルエクストーション）」と呼びます。

| 脅迫の材料 | 被害者が直面する問題 |
| --- | --- |
| データの暗号化 | データが利用できず、業務が止まる |
| 盗み出した情報 | 顧客情報や機密情報が公開されるおそれがある |

バックアップからデータを復旧できたとしても、すでに盗まれた情報の流出リスクは残ります。

また、暗号化を行わず、盗んだ情報の公開を材料として金銭を要求する攻撃も確認されています。警察庁はこの手口を「ノーウェアランサム」と呼んでいます。

## 身代金を支払うことに意味はあるのか

ここで、一つの疑問が生まれます。

犯罪者に金銭を支払ったところで、本当にデータを元に戻してくれるのでしょうか。

攻撃者が約束を守る保証はありません。

それでも、企業が支払いを検討する背景には、業務を停止し続けることによる損失があります。

例えば、次のような状況を考えてみましょう。

| 項目 | 仮定の金額・状況 |
| --- | ---: |
| 要求された身代金 | 3,000万円 |
| 1日あたりの業務停止による損失 | 1,000万円 |
| 自力での復旧に必要な期間 | 30日間 |
| 業務停止による損失の合計 | 3億円 |

企業にとっては、確実性がなくても、一刻も早く業務を再開したいという切迫した状況です。これは支払いを検討する背景を説明するための仮定であり、支払いを勧めるものではありません。

しかし、身代金を支払ったとしても、次の問題は残ります。

| 問題 | 支払いによる解決の保証 |
| --- | --- |
| 暗号化されたデータの復号 | ない |
| 破損したデータの完全復旧 | ない |
| 盗まれた情報の削除 | ない |
| 将来的な情報公開の防止 | ない |
| 再び攻撃されることの防止 | ない |

特に、デジタルデータは容易に複製できます。

攻撃者が盗んだデータを削除したと主張しても、そのコピーが別の場所に残っていないかを確認することは困難です。

警察庁も、支払いが復号を保証するわけではなく、犯罪活動を支える資金となる懸念があると説明しています。

## 侵入を防ぐだけでは十分ではない

ランサムウェア対策というと、ウイルス対策ソフトを導入することを想像するかもしれません。

しかし、どれほど対策を行っても、あらゆる攻撃を完全に防げるとは限りません。

そこで、セキュリティ対策では、侵入を防ぐことに加えて、被害の拡大を抑えることや、被害を受けた後に復旧できるようにすることも重要になります。

| 対策 | 目的 |
| --- | --- |
| ソフトウェアの更新 | システムの弱点を悪用される危険を減らす |
| 多要素認証 | アカウントの不正利用の危険を減らす |
| 不審なメールやファイルへの注意 | 感染のきっかけを減らす |
| アクセス権限の管理 | 被害が及ぶ範囲を制限する |
| ネットワークの分離 | 被害が他のシステムに広がることを抑える |
| バックアップ | データを復旧できるようにする |

それぞれが異なる役割を持つため、一つの対策だけに頼らないことが大切です。

## バックアップがあれば安心なのか

バックアップとは、データを失った場合に備えて、別の場所などに複製を保存しておくことです。

しかし、バックアップ先にも感染した端末から書き込みができる場合、バックアップまで暗号化されてしまう可能性があります。

| バックアップの状態 | 攻撃時に考えられること |
| --- | --- |
| 常時接続され、書き込み可能 | バックアップにも被害が及ぶ可能性がある |
| 攻撃の影響を受けにくいよう隔離されている | 復旧に使えるデータを残せる可能性が高まる |

重要なのは、バックアップを取ることだけではありません。

攻撃の影響を受けにくい状態で保存し、実際にデータを復旧できることまで確認しておく必要があります。

## 感染が疑われるときは

会社のパソコンで突然ファイルが開けなくなったり、身代金を要求する画面が表示されたりした場合は、通常の利用を中止します。

可能であればLANケーブルを抜く、Wi-Fiを切るなどして端末をネットワークから隔離し、速やかに会社の情報システム部門などへ報告します。組織の対応手順がある場合は、それに従います。

自己判断でファイルを削除したり、初期化したり、攻撃者に連絡したりしないことが重要です。警察のサイバー犯罪相談窓口への相談も検討します。

:::tip[今日のなるほど]
ランサムウェアは、情報を利用できなくすることや、情報が漏洩する危険性を利用して金銭を要求する攻撃です。

現代の企業は、情報がなければ事業を継続することが難しくなっています。

だからこそ、情報が人質として利用されるのです。

攻撃を完全に防ぐことだけでなく、攻撃を受けた場合にも被害を抑え、復旧できる状態を作っておくことが重要になります。

**情報を守るとは、情報を盗まれないようにすることだけではありません。必要なときに、必要な情報を利用できる状態を守ることでもあるのです。**
:::
