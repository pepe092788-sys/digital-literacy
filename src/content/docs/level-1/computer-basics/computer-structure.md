スマートフォンで写真を撮る。動画を見る。地図で目的地までの道を調べる。

私たちは毎日、コンピュータのお世話になっています。

でも、少し不思議だと思いませんか。

写真を表示することと、音楽を流すことと、計算をすること。まったく違う仕事なのに、どうして一台の機械で全部できるのでしょう。

実は、コンピュータが内部で行っていることを突き詰めると、驚くほど単純な処理の組み合わせになっています。

その中心にあるのが、**計算すること、情報を記憶すること、そして命令に従って動くこと**です。

## 1. コンピュータは、意外と融通が利かない

例えば、人間にこんなお願いをしたとします。

> この数字を、大きい順に並べておいて。

おそらく、細かい説明をしなくても理解してくれるでしょう。

でも、コンピュータは違います。

数字をどう比較するのか。どの順番で確認するのか。どこに結果を保存するのか。

そうした手順が必要です。

例えば、次の3つの数字を大きい順に並べる場合を考えてみましょう。

```text
並べ替える前：8、3、5
並べ替えた後：8、5、3
```

コンピュータは、数字を比較し、必要に応じて位置を入れ替えるような小さな処理を組み合わせて結果を出します。

コンピュータは、このような処理を非常に速く、何度も繰り返すことが得意です。

人間にとっては面倒な手順でも、コンピュータなら一瞬で終わることがあります。

## 2. コンピュータの中には、役割の違う部品がある

では、こうした処理を実際に行っているのは、どこなのでしょう。

代表的な部品を見てみましょう。

| 部品 | 主な役割 | 身近な例え |
| --- | --- | --- |
| **CPU** | 命令を読み取り、計算や比較などを実行する | 仕事を進める人 |
| **メモリ** | 実行中のプログラムや作業中の情報を一時的に保持する | 作業机 |
| **ストレージ** | ファイルやアプリなどを電源を切った後も保存する | 書類棚 |
| **入出力装置** | 人間や外部の機器と情報をやり取りする | キーボード・画面など |

例えば、パソコンで写真を開くときには、ストレージに保存された画像データが読み出され、メモリなどを使いながら処理され、画面に表示されます。

実際にはGPUなどの専用回路も処理に参加しますが、まずは**処理する場所・作業中の情報を置く場所・長く保存する場所が協力している**と考えれば十分です。

## 3. では、写真や音楽はどうやって計算するの？

ここで、最初の疑問に戻ってみましょう。

コンピュータが計算を得意とする機械なら、どうして写真を表示したり、音楽を流したりできるのでしょう。

その秘密は、**写真も音楽も、コンピュータの中では数字として扱える**ことにあります。

例えば、デジタル画像は、小さな点（ピクセル）の集まりとして表現できます。

各ピクセルの色を、赤・緑・青の成分で表す方式なら、次のような数値で色を指定できます。

| 色の例 | 赤（R） | 緑（G） | 青（B） |
| --- | ---: | ---: | ---: |
| 赤 | 255 | 0 | 0 |
| 緑 | 0 | 255 | 0 |
| 青 | 0 | 0 | 255 |
| 白 | 255 | 255 | 255 |

音楽も似ています。音の波を細かく測定し、数値の列として記録する方法があります。

こうして数字で表現できれば、コンピュータは計算によって画像の明るさを変えたり、音量を調整したりできます。

写真の明るさを変えるのも、音楽の音量を変えるのも、内部では数値に対する処理が行われているのです。

## 4. コンピュータが万能に見える理由

ここまでを整理すると、コンピュータには大きく3つの強みがあります。

1. **情報を数字として扱える。**
2. **決められた命令を高速に実行できる。**
3. **命令の組み合わせを変えることで、さまざまな仕事に対応できる。**

特に3つ目が重要です。

電卓は計算をする道具ですが、コンピュータは、実行するプログラムを変えることで、電卓にも、音楽プレーヤーにも、ゲーム機にもなれます。

つまり、**一台の機械が何でもできるように見えるのは、実行する命令を変えられるから**なのです。

もちろん、現代のコンピュータにはCPU以外にも、画像処理を得意とするGPUや、さまざまな専用回路が使われています。

それでも、情報を一定のルールで表現し、命令に従って処理するという基本的な考え方は共通しています。

:::tip[今日のなるほど]
コンピュータが特別なのは、何でも理解しているからではありません。

**さまざまな情報を数字で扱い、膨大な数の単純な処理を組み合わせられるからです。**

複雑に見えるアプリやシステムも、突き詰めれば小さな処理の積み重ねでできています。
:::

## おわりに ― 複雑なものも、小さな仕組みから

普段使っているスマートフォンも、会社の業務システムも、最新のAIも、突然魔法のように動いているわけではありません。

そこには、情報を表現する方法があり、処理する仕組みがあり、それらを組み合わせる工夫があります。

一つひとつの仕組みを知っていくと、これまで不思議だった技術が、少しずつ理解できるものに変わっていきます。

そして、その第一歩は意外とシンプルです。

**コンピュータは、ものすごい速さで、小さな仕事を積み重ねている。**

まずは、そのことを知っておくだけでも十分です。
