Python、JavaScript、HTML、CSS、Markdown、JSON、YAML。

ITについて学んでいると、さまざまな言語や記述形式に出会います。

どれも文字や記号を使って記述するものであり、一見すると、すべてプログラミング言語のようにも見えます。

しかし、それぞれがコンピュータに伝えようとしているものは異なります。

なぜ、一つの共通した書き方ではなく、これほど多くの記述形式が存在するのでしょうか。

## コンピュータに何を伝えるのか

例えば、飲食店のメニューをWebサイトに掲載することを考えてみましょう。

料理の名前や価格、写真、説明文を掲載し、注文ボタンを押すと合計金額が計算されるようにします。

一つのWebサイトですが、コンピュータに伝えなければならない情報には、さまざまな種類があります。

| 伝えたいこと | 具体例 |
| --- | --- |
| 文章 | じっくり煮込んだ特製カレー |
| データ | カレーライス、800円 |
| 構造 | 料理名を見出しにし、説明文や注文ボタンを配置する |
| 見た目 | 見出しの文字の色や大きさを決める |
| 処理 | 注文数から合計金額を計算する |

文章を表現することと、金額を計算することでは、必要な仕組みが異なります。

そこで、それぞれの目的に適した言語や記述形式が利用されています。

## 役割によって異なる記述形式

### プログラミング言語

**コンピュータに処理や動作を伝える**

```python
price = 800
quantity = 2

total = price * quantity
print(total)
```

800円の料理を2つ注文したときの合計金額を計算するプログラムです。

計算や条件分岐、繰り返しなど、コンピュータに行わせたい処理を記述できます。

代表例：Python、JavaScript、Java、C#

### マークアップ言語

**文章や文書の構造を伝える**

```html
<h1>カレーライス</h1>
<p>じっくり煮込んだ特製カレー</p>
```

どの部分が見出しで、どの部分が本文なのかを表現しています。

文章の内容だけでなく、その文章がどのような構造を持っているのかを伝えることができます。

代表例：HTML、Markdown、XML

### データ記述形式

**情報の内容や構造を伝える**

```yaml
name: カレーライス
price: 800
category: 食事
```

料理名、価格、カテゴリという情報を記述しています。

この情報を対応するプログラムが読み取ることで、価格の表示や商品の分類などに利用できます。

代表例：YAML、JSON、CSV、XML

### スタイルシート言語

**表示するものの見た目を伝える**

```css
h1 {
  color: brown;
  font-size: 24px;
}
```

見出しの文字色や大きさを指定しています。

文章そのものを変更することなく、表示方法を変更できます。

代表例：CSS

### クエリ言語

**必要なデータを取得したり、操作したりする**

```sql
SELECT name, price
FROM menu
WHERE price <= 1000;
```

データベースに保存されているメニューの中から、1000円以下の料理名と価格を取得する記述です。

データベースに対して、必要な情報や行いたい操作を伝えるために利用されます。

代表例：SQL、SPARQL

## 言語と記述形式の全体像

| 分類 | 主な役割 | 代表例 |
| --- | --- | --- |
| プログラミング言語 | 処理・動作 | Python、JavaScript、Java |
| マークアップ言語 | 文書の意味・構造 | HTML、Markdown、XML |
| データ記述形式 | 情報の内容・構造 | YAML、JSON、CSV、XML |
| スタイルシート言語 | 見た目・表示方法 | CSS |
| クエリ言語 | データへの問い合わせ・操作 | SQL、SPARQL |

これらは主な役割に着目した分類です。

XMLのように複数の用途を持つものもあり、すべてが明確に分かれているわけではありません。

## 同じ目的でも、異なる記述形式がある

データを記述する形式だけを見ても、YAML、JSON、XMLなど、複数の形式が存在します。

同じ料理の情報を、それぞれの形式で表現してみましょう。

**YAML**

```yaml
name: カレーライス
price: 800
```

**JSON**

```json
{
  "name": "カレーライス",
  "price": 800
}
```

**XML**

```xml
<menu>
  <name>カレーライス</name>
  <price>800</price>
</menu>
```

書き方は異なりますが、料理名と価格という共通した情報を表現しています。

なぜ、同じような情報を記述する形式が複数存在するのでしょうか。

それは、形式ごとに重視していることが異なるためです。

| 記述形式 | 主な特徴 |
| --- | --- |
| YAML | 人間が読み書きしやすく、設定ファイルなどに適している |
| JSON | 構造が比較的シンプルで、システム間のデータ交換に広く使われている |
| XML | 文書の構造や属性、名前空間などを表現できる |

人間が頻繁に編集する情報なのか、システム同士で交換する情報なのか、複雑な文書構造を表現する必要があるのか。

利用目的に応じて、適した記述形式は変わります。

また、技術が発展する中で、既存の形式では扱いにくかった問題を解決するために、新しい形式が生まれてきたという歴史的な背景もあります。

## 書かれた情報を誰が解釈するのか

どの記述形式も、書いただけでコンピュータが自動的に何かを行うわけではありません。

その書き方の規則を理解し、処理するソフトウェアが必要になります。

| 記述形式 | 解釈するソフトウェアの例 | 結果 |
| --- | --- | --- |
| HTML | Webブラウザ | Webページの表示 |
| Python | Pythonの実行環境 | 計算・処理の実行 |
| YAML | 対応するプログラム | データの読み込み・活用 |
| SQL | データベース管理システム | データの取得・操作 |

言語や記述形式とは、人間とソフトウェアの間で情報を伝えるための共通した規則でもあるのです。

## 役割を分けることで管理しやすくなる

冒頭の飲食店のWebサイトに戻ってみましょう。

料理の価格が変更されたとき、Webサイトの見た目まで作り直す必要はありません。

反対に、文字の色を変更したいとき、料理の価格や合計金額の計算方法まで変更する必要もありません。

データ、文章、見た目、処理をそれぞれ分けて管理することで、変更が必要な部分だけを修正しやすくなります。

さまざまな記述形式を使い分けることには、システムを管理しやすくするという意味もあるのです。

## AI時代における言語と記述形式

生成AIを利用すれば、自分が詳しく知らない言語や記述形式でも、文章やプログラムを生成できるようになりました。

すべての書き方を覚えておく必要はないかもしれません。

しかし、AIが生成したものが、処理を記述したものなのか、設定を記述したものなのか、画面の見た目を指定したものなのかを理解できれば、その内容を確認したり、適切な修正を依頼したりしやすくなります。

書き方を覚えることと、何のために使われているのかを理解することは、別の知識なのです。

:::tip[今日のなるほど]
コンピュータには、さまざまな言語や記述形式が存在します。

それは単に書き方が異なるからではなく、伝えたい情報や利用目的が異なるからです。

**何を伝えるためのものなのか。**

この視点を持つことで、初めて見る言語や記述形式に出会っても、その存在意義を理解しやすくなります。
:::
