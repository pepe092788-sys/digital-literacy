机の上に、ハサミと定規が置いてあります。

ハサミは紙を切る道具。定規は長さを測る道具。見た目も、使い方も違います。

では、スマートフォンに入っている電卓と地図アプリはどうでしょう。

同じ画面を使っているのに、一方は計算をして、もう一方は道案内をしてくれます。しかも、新しいアプリを入れるだけで、昨日までできなかったことができるようになります。

**機械を買い替えていないのに、使える道具が増える。**

これが、ソフトウェアの面白いところです。

## 1. 同じ機械が、別の道具になる

昔の道具は、できることが形によって決まっているものがほとんどでした。

時計は時刻を示し、カメラは写真を撮り、辞書は言葉の意味を調べるためのものです。

ところがスマートフォンは、アプリを切り替えるだけで、そのすべてをこなします。

なぜでしょう。

前の記事で、コンピュータは**命令を実行することで、さまざまな仕事をこなす**と説明しました。

その命令や、処理に必要な情報をまとめたものが、ソフトウェアです。

一方、画面、CPU、メモリ、キーボードといった、手で触れられる機械の部分は**ハードウェア**と呼びます。

| | ハードウェア | ソフトウェア |
| --- | --- | --- |
| 正体 | 物理的な装置や部品 | プログラムや関連データ |
| 例 | CPU、メモリ、画面、SSD | OS、ブラウザ、電卓アプリ |
| 役割 | 実際に処理や表示を行う | 何をどう処理するかを決める |

ハードウェアが道具の「体」だとすれば、ソフトウェアはその体を**どう動かすかを決める仕組み**です。

ただし、ソフトウェアは魔法ではありません。カメラのない機械に撮影アプリを入れても、写真は撮れません。できることは、ハードウェアの能力にも左右されます。

## 2. アプリとソフトウェアは、同じもの？

「アプリ」と「ソフトウェア」は、日常会話では似た意味で使われます。

でも、少しだけ範囲が違います。

**ソフトウェアは広い呼び名で、アプリケーションはその一種**です。

例えば、パソコンで文章を書くときに使うソフトは、アプリケーションソフトウェアです。利用者が何かをするための道具、と考えると分かりやすいでしょう。

一方、アプリを動かす土台になるソフトウェアもあります。

| 種類 | 代表例 | 主な役割 |
| --- | --- | --- |
| **アプリケーションソフトウェア** | ブラウザ、表計算、チャットアプリ | 利用者の目的に応じた仕事をする |
| **システムソフトウェア** | Windows、macOS、AndroidなどのOS | 機械やアプリが動く環境を整える |
| **デバイスドライバー** | プリンターや音声機器のドライバー | OSなどと機器の間を取り持つ |

※デバイスドライバーは、システムソフトウェアの一部として扱われることもあります。分類は厳密に一通りではありません。

普段はアプリの存在を意識していても、OSやドライバーを意識することは少ないかもしれません。

けれど、見えないところで働くソフトウェアがなければ、アプリも思うようには動けません。

## 3. 「印刷」ボタンの裏側には、たくさんの協力者がいる

例えば、文書を印刷するとします。

私たちがするのは、画面の「印刷」ボタンを押すことだけです。

でも、内部では複数のソフトウェアが協力しています。

```text
利用者
  ↓ 「印刷」を押す
文書アプリ
  ↓ 印刷したい内容を渡す
OS・印刷の仕組み
  ↓ プリンター向けに処理する
デバイスドライバーなど
  ↓ 機器とやり取りする
プリンター
  ↓
紙に印刷される
```

※実際の処理経路は、OSやプリンターの方式によって異なります。

文書アプリが、世界中のプリンターの細かな動かし方をすべて知っている必要はありません。

共通の仕組みを通じて、ほかのソフトウェアに仕事を頼めるからです。

ここには、ITの重要な考え方が隠れています。

**複雑な仕事を、小さな役割に分けて協力させる。**

これはソフトウェアの種類だけでなく、システム設計やネットワークを理解するときにも役立つ考え方です。

## 4. ソフトウェアは、どこに存在するのか

「形のない道具」と言いましたが、ソフトウェアがどこにも存在しないわけではありません。

プログラムやデータは、SSDなどのストレージに、デジタル情報として記録されています。

アプリを起動すると、必要なプログラムやデータがメモリに読み込まれ、CPUなどが命令を実行します。

つまり、ソフトウェアは物理的な記録媒体に保存され、ハードウェアの働きによって動きます。

さらに、ソフトウェアは必ずしも自分の端末にすべて入っているとは限りません。

例えば、ブラウザで利用するWebサービスでは、手元の端末とインターネットの向こうにあるサーバーが、それぞれ処理を分担することがあります。

「アプリを使っている」という一言の裏にも、いろいろな動き方があるのです。

## 5. 形がないからこそ、変えられる

ハサミの切れ味を大きく変えるには、刃を研いだり、別のハサミを用意したりする必要があります。

でも、ソフトウェアならプログラムを変更し、新しいバージョンを配布することで、同じ機械に新しい機能を追加できる場合があります。

もちろん、変更には不具合や互換性の問題も伴います。それでも、機械そのものを作り直さずに道具の働きを変えられるのは、大きな特徴です。

だからこそ、一台のスマートフォンが、地図にも、カメラにも、音楽プレーヤーにもなれるのです。

:::tip[今日のなるほど]
**ハードウェアが「実際に動く機械」なら、ソフトウェアは「その機械に何をさせるかを決める仕組み」です。**

アプリはソフトウェアの一種。そしてアプリの裏側では、OSやドライバーなど、別のソフトウェアも働いています。

同じ機械がいろいろな道具になれるのは、ソフトウェアを切り替えたり、更新したりできるからです。
:::

## おわりに ― 画面の向こうの、見えない道具箱

スマートフォンのホーム画面を眺めてみてください。

そこには、物理的な道具なら何十個も必要だった仕事が、小さなアイコンとして並んでいます。

そして、アイコンのない場所にも、OSやドライバーのようなソフトウェアが働いています。

**コンピュータは一台でも、その中にはたくさんの「形のない道具」がある。**

そう考えると、普段何気なく使っているアプリも、少し違って見えてきませんか。
