---
title: コンピュータとは何か
description: 入力・処理・出力を、電卓を例にして学びます。
---

コンピュータは、受け取ったデータを、プログラムに書かれた手順に従って処理する機械です。スマートフォンや身近な家電の中にもコンピュータが入っています。

## 入力・処理・出力

電卓で `2 + 3` を計算する場面を考えてみましょう。

| 段階 | 電卓の例 |
| --- | --- |
| 入力 | 数字と演算記号をボタンで入力する |
| 処理 | 入力された指示に従って、2 と 3 を足す |
| 出力 | 計算結果の 5 を画面に表示する |

入力にはボタンのほかにマイクやセンサーなども使われます。出力にも画面表示、音、ほかの機器へのデータ送信などがあります。

## プログラムの役割

同じ数字を入力しても、足し算と掛け算では結果が変わります。どのように処理するかは、入力された指示とプログラムに書かれた手順によって決まります。

身近な機器を一つ選び、どんなデータを受け取り、どう処理し、何を出力しているか考えてみましょう。
