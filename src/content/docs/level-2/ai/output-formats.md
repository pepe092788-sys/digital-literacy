AIに「資料を作って」と頼んで画像が返ってきたものの、あとから文字を修正したくなったとします。完成した画像に描かれた文字は、PowerPointのテキストボックスのように編集できるとは限りません。

どの形式で成果物を受け取るかは、資料を作った後の利用方法にも関係します。

## 主な出力形式

| 形式 | 特徴 | 向いている用途 |
| --- | --- | --- |
| PNG | ラスター画像。可逆圧縮と透過に対応 | 文字・図解・Web掲載 |
| JPEG | ラスター画像。一般に非可逆圧縮 | 写真、容量を抑えた画像 |
| SVG | 図形や文字をベクターで表現できる | 拡大する図、アイコン |
| PDF | レイアウトを維持しやすい文書形式 | 印刷・配布 |
| PPTX | スライドや要素を編集できる形式 | 発表・共同修正 |
| HTML | ブラウザで表示する文書形式 | Web教材・操作機能 |
| GIF | 静止画や短いアニメーション | 簡易な動きの説明 |
| MP4 | 動画・音声を格納できる形式 | 解説動画 |

PNGやJPEGは画素の集合であり、文字や図が独立した編集要素とは限りません。SVGでも埋め込まれたラスター画像は拡大によって粗くなることがあります。

PDFは文書の見え方を維持しやすい一方、元の編集可能なデータを必ず保持するわけではありません。PPTXも一枚の画像を貼り付けた作りなら、画像内の文字を個別に編集することは困難です。

HTMLはそれだけで操作を実現するとは限りませんが、JavaScriptなどと組み合わせて操作できる教材を作れます。

## 目的から逆算する

| 希望 | 指示の例 |
| --- | --- |
| 印刷配布したい | A4縦の印刷用PDF |
| Web記事に画像を載せたい | 読みやすい解像度のPNG |
| 後から文字・図を修正したい | 要素を個別に編集できるPPTX |
| 拡大して見たい | ベクター要素で構成したSVG |
| 操作しながら学びたい | 実際に動作するHTML教材 |

画像を生成してほしいのか、編集可能な資料を作ってほしいのか、動作するWebコンテンツを作ってほしいのかを区別します。利用するAIサービスによって対応できる形式は異なるため、出力可能な形式と編集・動作の状態を確認します。

## 今日のなるほど

成果物の形式は単なる拡張子の違いではありません。印刷、修正、公開、操作といった、資料を作った後に何をするのかを考えて選ぶものです。
