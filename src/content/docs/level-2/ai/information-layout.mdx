## レイアウト・資料構成の語彙

| 用語 | 特徴・適した用途 |
| --- | --- |
| ベントーグリッド | 大小の区画で情報をまとめる |
| カードレイアウト | 項目ごとに独立したカードで並べる |
| エディトリアルデザイン | 雑誌・書籍のように見出し、本文、図を配置する |
| ワンページャー | 一つのテーマを1枚で完結させる |
| チートシート | 必要な知識・手順をすぐに参照できる早見表 |
| ビジュアルディクショナリー | 図と用語を対応させる図鑑形式 |
| ストーリーボード | 場面を順番に並べる |
| ダッシュボード | 複数の重要指標をまとめて確認する画面 |

この表には純粋な配置手法だけでなく、資料全体の用途や構成を指定する言葉も含まれます。例えばワンページャーは枚数の指定、チートシートは参照用という用途の指定でもあります。

## 配置は読み手の行動を変える

資料を順に読んで理解してほしいなら見出しと文章の流れを作ります。後から確認してほしいなら項目ごとの早見表にします。数値を継続的に比較する場合にはダッシュボードが候補になります。

どの場合も見出しの大小、余白、近接した項目のまとまりによって情報の優先順位を伝えます。無理に一枚に収めて文字が読めなくなれば、目的を達成できません。

## AIへの依頼例

> コンピュータの3つの部品の役割を、見返しやすいチートシートとしてまとめてください。各部品名、役割、身近な例を同じ順番で並べてください。A4で読める文字サイズにしてください。

## 今日のなるほど

見た目がきれいかどうかだけではなく、読者が欲しい情報にたどり着きやすいかを考えることがレイアウトの役割です。
