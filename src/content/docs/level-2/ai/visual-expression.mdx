コンピュータの仕組みを教える資料を作るとします。CPUは命令を実行し、メモリは作業中のデータを保持し、ストレージはデータを長期保存する。この説明を変えずに、見せ方だけを変えるとどうなるでしょうか。

## 表現方法の特徴と指示例

| 用語 | 特徴・向いている用途 | AIへの指定例 |
| --- | --- | --- |
| グラフィックレコード | 話の全体像やつながりをイラストと文字で記録 | グラレコ風の手描き図解に |
| インフォグラフィック | 数値や要点を図表・アイコンで伝える | 要点を比較できるインフォグラフィックに |
| スケッチノート | 個人の学習メモのように要点をまとめる | イラスト入りの手書きノート風に |
| ホワイトボード風 | 講師が板書して説明するような表現 | ホワイトボードに描くように |
| アイソメトリック | 立体的な空間や部品の表現 | 等角投影風のイラストに |
| フラットデザイン | 陰影や装飾を抑えた平面的な表現 | シンプルなフラットデザインに |
| ブループリント風 | 設計図の雰囲気で構成を見せる | 青地に白線の設計図風に |
| コミック形式 | 会話や場面を使って伝える | 3コマの会話形式に |
| ビジュアルメタファー | 身近な物に例えて抽象概念を伝える | CPUを作業する人に例えて |
| ピクトグラム | 単純化した記号で意味を伝える | アイコン中心の案内図に |

本来のグラフィックレコーディングは会議や講演を視覚的に記録する手法です。AIに後から資料を作らせる場合は「グラレコ風」と呼ぶ方が適切です。ピクトグラムは資料全体の形式ではなく、図中に使う記号の表現方法です。

## どのように選ぶか

概要をつかむならグラレコ風、数値を比較するならインフォグラフィック、空間の構成なら立体図が候補になります。ただし、立体的に見えるからといって実際の構造を正確に示しているとは限りません。例え話も概念への入口であり、実物と同じ仕組みではありません。

画像生成では日本語の誤字や部品名の取り違えも起こり得るため、ラベルや因果関係を確認しましょう。

## 今日のなるほど

見せ方を変えても、伝えるべき事実は変わりません。目的に合った視覚表現を選ぶことが、情報を理解しやすくする第一歩です。
