画像を見て仕組みを学ぶこともできますが、自分で条件を変えて結果を確かめられたら、また違った理解が生まれます。インタラクティブとは、利用者からの操作に応じて情報や状態が変わることです。

## 実際に操作してみる

8 GBのメモリを持つ仮想のコンピュータで、一つのアプリが1.5 GBを使用すると仮定します。下のスライダーを動かすと、使用量の表示が変化します。

<InformationDesignSamples kind="interactive" />

静止画像にスライダーを描くことはできますが、それだけでは操作に反応しません。この例では入力値を読み取り、使用量を計算し、表示を更新するプログラムが動いています。

## 動きや体験を指定する言葉

| 用語 | 何が起こるか |
| --- | --- |
| スタティック | 表示内容は静止している |
| アニメーション | 時間に応じて表示が変わる |
| モーショングラフィックス | 文字・図形などを動かして伝える |
| インタラクティブ | 利用者の操作に応じて変化する |
| シミュレーション | モデルの条件を変えて結果を観察する |
| スクロリーテリング | スクロールに合わせて説明が展開する |
| インタラクティブクイズ | 回答に応じて結果や説明を返す |
| ゲーミフィケーション | 学習などにゲームの要素を取り入れる |

アニメーションは操作できるとは限りません。シミュレーションは必ずしもインタラクティブではなく、事前に計算した結果を表示するものもあります。

## AIへの依頼例

> メモリ容量と仮のアプリ使用量の関係を説明する、スライダーで条件を変えられるHTML教材を作ってください。数値の前提と実際の機器との違いを明記してください。

実際に動作する教材には、HTMLに加えてJavaScriptなどの実装や対応する実行環境が必要になる場合があります。AIが作ったシミュレーションは、計算式や前提条件も検証してから利用します。

## 今日のなるほど

動くことと操作できることは別です。インタラクティブな教材では、読み手の操作そのものが理解を助ける手段になります。
