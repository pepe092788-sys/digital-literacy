ある会社が、採用活動の効率化のためにAIを導入しました。

応募者の書類をAIに読み込ませ、採用候補者を選ぶための評価を出してもらいます。

担当者は大量の書類を一枚ずつ確認する手間を減らせるようになります。

しかし、AIは何を基準に応募者を評価しているのでしょうか。特定の人に不利な判断をしていないでしょうか。AIの評価に誤りがあった場合、誰が責任を負うのでしょうか。

システムが正常に動作していることと、その判断が適切であることは同じではありません。

## AIガバナンスとは

AIガバナンスとは、組織がAIの活用によって価値を生み出しながら、AIがもたらすリスクや社会への影響を適切に管理するために、方針・責任・意思決定・監督の仕組みを整えることです。

ITガバナンスと共通する考え方を土台としながら、AIによる予測や生成、判断が人間や社会に与える影響にも目を向けます。

AIの利用を許可するかどうかだけではなく、何のために使い、どの範囲まで任せ、結果をどのように確認するのかを組織として考える必要があります。

## なぜAIには特有の考慮が必要なのか

例えば、従来のプログラムでは、あらかじめ記述された条件に従って処理を行うものがあります。

一方、機械学習を利用したAIは、学習したデータに含まれる傾向などをもとに予測や判断を行います。生成AIでは、もっともらしく見える誤った情報を出力することもあります。

学習データの偏り、利用する環境の変化、モデルの更新などによって、期待していた品質が維持されないこともあります。

従来のITにも公平性や説明責任、品質管理は必要ですが、AIの活用ではこれらが特に重要になる場面があります。

| 視点 | AI活用で特に考えること |
| --- | --- |
| 安全性・プライバシー | 入力した情報は適切に扱われるか。危険な出力を防げるか |
| 信頼性 | 予測や生成結果をどのように検証するか |
| 公平性 | データや判断に偏りがあり、特定の人に不利益を与えていないか |
| 透明性 | AIを使っていることや判断の根拠、限界を必要に応じて説明できるか |
| 人間による監督 | どこまでAIに任せ、どこで人間が介入するか |
| 説明責任 | 誰が方針と結果に責任を持ち、問題が起きたときに対応するか |

経済産業省・総務省のAI事業者ガイドラインでも、人間中心、安全性、公平性、プライバシー保護、透明性、アカウンタビリティ（説明責任）などが共通の指針として示されています。

参考：[経済産業省「AI事業者ガイドライン」](https://www.meti.go.jp/shingikai/mono_info_service/ai_shakai_jisso/20260331_report.html)

## AIに任せる範囲を決める

AIは、文章の作成を補助することも、業務上の判断を提案することも、一定の範囲で処理を自動化することもできます。

しかし、AIの性能が高いからといって、すべての判断を任せてよいわけではありません。

<AIGovernanceDiagrams kind="delegation" />

例えば、会議の議事録の下書きを作る場合と、採用候補者の選定や設備の安全に関わる判断を行う場合では、誤った結果が与える影響が異なります。

採用の例では、AIに書類の整理や評価の補助をさせることと、AIだけで不採用を決めることは別の判断です。

人間が確認する仕組みを設ける場合も、単に承認ボタンを押すだけでは十分ではありません。判断の根拠や限界を確認でき、必要に応じてAIの提案を修正・却下できる権限と能力が必要です。

自動処理を認める場合には、対象範囲を定め、異常時に人間へ引き継ぐ条件や停止方法を決めておくことも重要です。

**AIにどこまで任せるのかは、技術の性能だけでなく、判断を誤ったときの影響を考えて決めるものです。**

## AI利用ガイドラインはガバナンスの一部

会社でAIを活用する際、利用ガイドラインを作成することがあります。

入力してよい情報、利用できるサービス、禁止事項などを定めることは重要です。

しかし、ガイドラインが存在するだけでは、その内容が実際に守られているか、組織として期待した効果を得られているかは分かりません。

<AIGovernanceDiagrams kind="structure" />

| 取り組み | 役割 |
| --- | --- |
| AI活用方針 | 組織として何を目指すのかを定める |
| AI利用ガイドライン | 利用条件や守るべきルールを示す |
| 審査・承認制度 | 利用目的とリスクに応じて導入を判断する |
| 人材育成 | AIの限界を理解し、適切に判断できる人材を育てる |
| モニタリング | 利用状況・成果・品質・問題を把握する |
| 継続的な改善 | 技術や業務環境の変化に応じて方針や運用を見直す |

例えば、新たにAIで書類を評価する仕組みを導入するなら、導入前に評価基準やリスクを確認し、導入後も結果に偏りや問題がないかを確認します。モデルや利用目的が変わった場合には、必要に応じて再評価します。

AIガバナンスは、導入前の審査だけではなく、開発・導入・利用・変更・終了まで継続するものなのです。

参考：[NIST「AI Risk Management Framework」](https://www.nist.gov/itl/ai-risk-management-framework)

## AIガバナンスは活用を促進するためにもある

リスクを避けることだけを考えると、AIの利用を禁止するという結論になりかねません。

しかし、それではAIによって得られる価値も失われてしまいます。

組織として利用目的や許容できるリスクを定め、安全に利用できる環境を提供し、新しい活用方法を相談・審査できる仕組みがあれば、現場は判断に迷ったときの相談先を持てるようになります。

禁止だけではなく、適切な活用を支える仕組みを整えることは、シャドーAIの発生を減らすことにもつながります。

## 今日のなるほど

冒頭の採用活動では、AIを利用することで書類の確認にかかる時間を減らせる可能性がありました。

一方で、採用という人の将来に関わる判断には、公平性や説明責任、人間による監督が求められます。

AIの性能を評価するだけではなく、組織としてAIに任せる範囲を決め、その結果を確認し、必要に応じて利用方法を見直すことが大切です。

**AIの能力が高まるほど、人間にはAIの活用範囲を決め、結果に責任を持つための仕組みが求められるのです。**
