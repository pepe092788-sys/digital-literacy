高度な専門性を発揮する段階や、組織全体の活用・運営・戦略を考える段階で必要となる知識を扱う階層です。

技術の内部構造や設計思想、専門的な理論を深めることに加え、個人のIT活用から視野を広げ、組織全体でどのように技術を活用し、価値やリスクを管理するのかという知識も扱います。
